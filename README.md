# Atelier North — Business Website

A responsive, multi-section creative studio website built with plain HTML, CSS and JavaScript. The design is intentionally different from a typical tech agency template: warm paper tones, editorial serif typography, clay accents, spacious layouts and CSS-made portfolio artwork.

## Files

- `index.html` — page structure, content, navigation, sections and contact links
- `style.css` — full visual design, typography, responsive layouts and CSS artwork
- `script.js` — mobile navigation, current year and contact-link notice

## Before publishing

1. Open `index.html`.
2. Replace `hello@ateliernorth.example` with your real business email in both the visible email text and `mailto:` links.
3. Replace the studio name, services, portfolio concepts and copy with your actual business information.
4. Google Fonts are loaded online. If you want the site to work without internet access, use system font fallbacks or self-host properly licensed font files.
5. The work section is marked as concept artwork. Replace it with genuine project images and accurate descriptions before presenting it as a real portfolio.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository, for example `atelier-north`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish the site. The Pages section will show the published URL.

## Important

This is a static frontend website. It does not include a database, server, admin panel, user accounts, online payments, or a server-side contact form. A real contact form or other backend feature needs a secure service or backend implementation.
